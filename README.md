# FreeSpark | סיפורי גמילה מודרניים

ספריית סיפורים קצרים בעברית שמדגימים הרגלי נשימה, בחירה ותנועה כחלופה לדפוסי התמכרות. כל הדמויות מנוכרות משמות פרטיים ומסומנות כפלוני/אלמוני כדי לשמור על ניטרליות ולאפשר הזדהות רחבה.

## חזון
- לספק אוסף סיפורים מודרניים, קצרים ויישומיים שעוזרים למטפלים, יוצרים ואנשים פרטיים לייצר שיחה חיובית על גמילה והרגלים בריאים.
- לשמור על חומר גלוי ונגיש (Open Content) שמאפשר התאמה אישית לתסריטים, קריינות, קלפים טיפוליים ואתרי תוכן.
- לנהל תיעוד שקוף, גרסאות ברורות ותהליכי תרומה פשוטים בעברית.

## שימוש מהיר
- **קריאה מיידית:** פתחו ישירות כל קובץ סיפור (`*.md`) או את `index.html` לתצוגת כרטיסיות.
- **חיפוש לפי נושא:** שמות הקבצים מתחילים באימוג׳י ונושא (למשל `🌱 סיפור 1 – הסיגריה האחרונה בתחנה.md`).
- **יצירת עותק מוקרא/תסריט:** כל סיפור מחולק לקטעי משנה עם כותרות Emoji לניווט מהיר.
- **הוספת סיפור חדש:** העתיקו תבנית קיימת, שמרו על מבנה כותרות, ועל שימוש בשמות פלוני/אלמוני בלבד.

## תיעוד מקוצר
- **רישיון:** ראה `LICENSE` (MIT) לשימוש חופשי עם ייחוס.
- **יומן גרסאות:** `CHANGELOG.md` לפי SemVer + תאריך עברי/לועזי כשיש.
- **תרומות:** `CONTRIBUTING.md` (זרימת עבודה, בדיקות וסטנדרט קומיטים) ו-`CODE_OF_CONDUCT.md` (מרחב בטוח לדיון ויצירה).
- **אבטחה:** `SECURITY.md` להסלמת פגיעויות ו-SLA מענה.
- **שחרורים:** `RELEASING.md` (תיוג גרסאות, בדיקות, עדכון `VERSION`).
- **ממשל:** `GOVERNANCE.md` (קבלת החלטות, בעלויות) ו-`CODEOWNERS` (ביקורות אוטומטיות).
